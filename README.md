# Все для кухні — інтернет-магазин (React + SCSS)

Адаптивний демонстраційний магазин на React + Vite. У каталозі є розділи «Ремонт», «Техніка для кухні» та «Посуд».

## Запуск
``` 
"clean": "rimraf dist",
"dev": "vite",
"build": "vite build",
"preview": "vite preview",
"deploy": "gh-pages -d dist"
```

## Де редагувати
- `src/data/catalog.js` — назви, ціни, описи, характеристики та фото товарів.
- `src/styles/` — оформлення.
- `src/components/CartDrawer.jsx` — оформлення замовлення.
- `src/components/Footer.jsx` — контактні дані магазину.

## Важливо перед запуском реального магазину
- Товари, ціни та характеристики в `src/data/catalog.js` демонстраційні.
- Якщо не задано `image`, замість фото показується емодзі. Додайте зображення до `public/img/` і вкажіть шлях, наприклад `/img/product.jpg`.
- Оформлення замовлення працює лише як демо: дані можуть зберігатися у `localStorage` цього браузера, але власник магазину їх не отримує. Інтерфейс прямо повідомляє про це. Для реального приймання замовлень потрібен сервер або інтеграція з CRM/сервісом замовлень.
- Додайте справжній телефон, email і графік роботи перед запуском.
- Вкажіть і перевірте фактичні умови доставки, повернення та гарантії перед публікацією.

## Публікація на GitHub Pages

У репозиторії налаштовано GitHub Actions (`.github/workflows/deploy.yml`). Workflow запускається після push у гілку `main` або вручну.

1. Відкрийте **Settings → Pages** у GitHub.
2. У **Build and deployment → Source** виберіть **GitHub Actions**.
3. Переконайтеся, що зміни відправляються у гілку `main`. GitHub Actions встановить залежності, збере проєкт у `dist`, перевірить згенеровані шляхи та опублікує готовий сайт.

Для репозиторію `UlichIgor/kitchen-shop` базовий шлях Vite встановлено як `/kitchen-shop/` у `vite.config.js`.

**Важливо:** `src/main.jsx` — вихідний файл React, а не окрема вебсторінка. Після збірки Vite переносить його код у файли `assets/*.js` всередині `dist`. Тому адреса `https://ulichigor.github.io/src/main.jsx` закономірно повертає 404. Відкривати потрібно сайт: <https://ulichigor.github.io/kitchen-shop/>.

Якщо сайт показує стару версію або 404 після змін:
1. Перевірте вкладку **Actions** у репозиторії та дочекайтеся успішного завершення `Deploy to GitHub Pages`.
2. У **Settings → Pages → Build and deployment → Source** має бути вибрано **GitHub Actions**.
3. Переконайтеся, що зміни відправлено у гілку `main`.
4. Оновіть сторінку без кешу (`Ctrl + F5`).
